# Roadmap

- [x] v0.1 foundation: FastAPI, configurable LLM adapter, SQLite conversation history.
- [ ] v0.2 memory: user-approved durable facts, retrieval, edit/delete controls and tests.
- [ ] v0.3 research: search, page extraction, source tracking, citations and prompt-injection defenses.
- [ ] v0.4 agent loop: task queue, planning, tool allowlist, budgets and audit log.
- [ ] v0.5 VPS: authenticated remote deployment, backups and monitoring.
- [ ] v0.6 voice: speech-to-text and text-to-speech adapters.
- [ ] v1.0 clients: responsive web interface and phone-friendly voice/text experience.

Each stage must have a working demo and tests before the next stage begins.

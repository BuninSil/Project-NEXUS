# Project NEXUS

Личный local-first ИИ-компаньон: собственная идентичность, долговременная память, исследование знаний, подключаемые языковые модели и безопасная агентная работа с компьютером.

> Текущий статус: **v0.1 foundation scaffold**. Структура проекта создана, но запуск на целевой машине и прохождение тестов ещё предстоит подтвердить.

## Главная цель

NEXUS должен постепенно развиться в самостоятельного интеллектуального компаньона с естественным диалогом, устойчивой памятью, индивидуальным характером, способностью изучать проверяемые источники и выполнять задачи на компьютере с разрешения пользователя.

**Платные API и внешние модели не должны быть обязательными для работы ядра.** Внешние и локальные модели могут подключаться через сменные адаптеры, но память, идентичность, инструменты, планирование и базовые функции принадлежат самому NEXUS.

Долгосрочная цель включает собственные языковые технологии и исследование компактной языковой модели. Это постепенная исследовательская задача, а не обещание повторить возможности frontier-моделей на домашнем оборудовании.

## Что заложено в текущем фундаменте

- FastAPI HTTP API: `GET /health`, `POST /chat`, `GET /memory/recent/{conversation_id}`.
- SQLite для истории диалогов.
- Сменный OpenAI-compatible адаптер (например, локальный Ollama endpoint или совместимый сервис).
- Конфигурация через `.env`, секреты не хранятся в Git.
- Разделение модулей, чтобы менять языковую модель без переписывания ядра.

**Важно:** текущий scaffold пока использует настроенный model endpoint для генеративного ответа. Полностью автономный fallback без модели ещё предстоит реализовать.

## Быстрый запуск

Требуется Python 3.11+.

```bash
python -m venv .venv
# Windows PowerShell:
.venv\\Scripts\\Activate.ps1
# Linux/macOS:
# source .venv/bin/activate
pip install -r requirements.txt
copy .env.example .env  # Windows; на Linux/macOS: cp .env.example .env
uvicorn nexus.main:app --reload
```

Открой `http://127.0.0.1:8000/docs` для Swagger UI.

Для текущего LLM-адаптера укажи `LLM_BASE_URL`, `LLM_MODEL` и при необходимости `LLM_API_KEY`. Это временный подключаемый путь, а не обязательная зависимость будущего ядра.

## Принципы проекта

1. **Local-first:** ядро должно запускаться без платного API и без внешней модели.
2. **Память принадлежит NEXUS:** история, одобренные факты и опыт переживают смену модели.
3. **Контролируемое обучение:** память, обучающие примеры и веса модели разделены; обучение проводится отдельными проверяемыми этапами.
4. **Проверяемые знания:** интернет-источники сохраняются с происхождением, датой и оценкой надёжности; веб-страницы считаются недоверенными.
5. **Безопасная агентность:** инструменты ограничены разрешениями, действия журналируются, разрушительные и внешние действия требуют подтверждения.
6. **Постепенное развитие:** сначала рабочее ядро, затем память и исследование, native NLP, небольшие модели, агентность и эксперименты с собственной LLM.
7. **Честные ограничения:** небольшой локальный проект не объявляется эквивалентом ChatGPT; возможности подтверждаются тестами и демонстрациями.

## Оборудование

- HP 250 G7: лёгкая разработка, API, SQLite, тесты и детерминированные компоненты; не предназначен для обучения или обслуживания крупной LLM.
- Основной ПК: разработка и ограниченные эксперименты с небольшими моделями.
- Будущий VPS: постоянное ядро, память, планировщик и исследовательские задачи; наличие VPS само по себе не делает крупный inference бесплатным.
- Телефон: клиент и удалённое управление.

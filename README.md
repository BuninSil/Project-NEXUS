# Project NEXUS

Личный local-first ИИ-компаньон: собственная идентичность, долговременная память, исследование знаний, подключаемые языковые модели и безопасная агентная работа с компьютером.

> Текущий статус: **v0.2.1 — базовое ядро проверено на Windows; первый браузерный интерфейс добавлен, локальная проверка интерфейса ожидается.**

## Главная цель

NEXUS должен постепенно развиться в самостоятельного интеллектуального компаньона с естественным диалогом, устойчивой памятью, индивидуальным характером, способностью изучать проверяемые источники и выполнять задачи на компьютере с разрешения пользователя.

**Платные API и внешние модели не должны быть обязательными для работы ядра.** Внешние и локальные модели могут подключаться через сменные адаптеры, но память, идентичность, инструменты, планирование и базовые функции принадлежат самому NEXUS.

Долгосрочная цель включает собственные языковые технологии и исследование компактной языковой модели. Это постепенная исследовательская задача, а не обещание повторить возможности frontier-моделей на домашнем оборудовании.

## Что уже работает

- FastAPI API: GET /health, POST /chat, GET /memory/recent/{conversation_id}.
- SQLite для локальной истории сообщений.
- Встроенный режим без языковой модели: /help, /status и честный ответ об ограничениях.
- Сменный OpenAI-compatible адаптер для подключаемой модели.
- Конфигурация через .env; секреты не хранятся в Git.
- Первый запуск на Windows подтверждён владельцем: зависимости установлены, 5 тестов прошли, сервер Uvicorn запущен.

## Браузерный интерфейс

После запуска сервера открой **http://127.0.0.1:8000/**. Интерфейс использует тот же локальный API и SQLite:
- отправка сообщений через POST /chat;
- восстановление последних сообщений текущего диалога;
- новый диалог с отдельным идентификатором;
- индикатор доступности ядра и режима модели;
- адаптивная раскладка для компьютера и телефона.

Интерфейс не добавляет генеративный интеллект сам по себе. Без LLM_MODEL NEXUS остаётся во встроенном режиме. Для полноценной генерации можно подключить совместимую локальную или внешнюю модель.

## Быстрый запуск

Требуется Python 3.11+.

```bash
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# Linux/macOS:
# source .venv/bin/activate
pip install -r requirements.txt
uvicorn nexus.main:app --reload
```

Открой http://127.0.0.1:8000/ для чата или http://127.0.0.1:8000/docs для Swagger UI.

Проверка:

```bash
pytest -q
```

## Принципы проекта

1. Local-first: ядро запускается без платного API и внешней модели.
2. Память принадлежит NEXUS: история, одобренные факты и опыт переживают смену модели.
3. Контролируемое обучение: память, обучающие примеры и веса модели разделены.
4. Проверяемые знания: источники сохраняются с происхождением; веб-страницы считаются недоверенными.
5. Безопасная агентность: инструменты ограничены разрешениями и журналируются.
6. Постепенное развитие: память, исследование, native NLP, модели, агентность и собственная LLM.
7. Честные ограничения: возможности подтверждаются тестами и демонстрациями.

## Оборудование

- HP 250 G7: лёгкая разработка, API, SQLite и тесты; не предназначен для обучения крупной LLM.
- Основной ПК: разработка и ограниченные эксперименты с небольшими моделями.
- Будущий VPS: постоянное ядро, память и исследовательские задачи.
- Телефон: клиент и удалённое управление.
